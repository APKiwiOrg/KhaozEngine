# KhaozEngine change notes

High-level history, newest first. One or two sentences per release; full detail in [CHANGELOG.md](CHANGELOG.md).

- **7.13.0**: JSONC (JSON with comments + trailing commas) is now the documented engine standard for hand-authored config, manifests, settings, and saves. New `KhaozEngine.Serialization.Jsonc` is the single read policy all engine JSON loads route through (`Options`/`DocumentOptions`/`NodeOptions` plus `Deserialize`/`DeserializeFile`/`ParseDocument`/`ParseNode`); `JsonDefaults.TolerantRead` is now the same instance. `JsonSchemaValidator` and `WorldSerializer.Load` were routed through it (hand-edited saves with comments now load). Read-time only: writing stays plain JSON (`IndentedWrite`), and signed/wire formats (Updates manifest, AOT apply-config) keep strict options by design.
- **7.12.0**: Fix multi-instance skinned meshes (drawing several skinned meshes in one frame rendered all but the first as invisible/garbage on Metal). The bone palette is now a per-draw dynamic-offset uniform buffer (each skinned draw reads its own bone slot via a rebind), each skinned `DrawSkinned` is its own draw, and one mesh is capped at 128 bones. Public skinned API unchanged; adds dynamic-offset resource bindings (`GpuBufferRange`, `SetGraphicsResourceSet(..., dynamicOffset)`) to `KhaozEngine.Gpu`.
- **7.11.0**: Runtime skinned/deformable meshes in Render3D (GPU bone-palette skinning). `Scene3D.LoadSkinnedMesh`/`DrawSkinned`, procedural tube builder + glb rig loader, code-driven bone control for tentacles/limbs/cables. Caller supplies joint world transforms (bones are independent; FK is the caller's job). Presentation only.
- **7.10.0**: New `KhaozEngine.Determinism` package: `DeterministicFpScope` forces the CPU floating-point environment to a canonical IEEE state (round-to-nearest, FTZ/DAZ off, traps masked) for the duration of a fixed-tick / lockstep sim, then restores it. Fixes host-sim drift caused by the uncontrolled per-thread FP control register (ARM64 `FPCR`, x86 `MXCSR`) varying across threads/machines/process runs (the SpaceGame tripwire gave two final states from one seed on one machine). RAII `Enter()` (allocation-free) or `SetCanonical()`/`Restore()` per sim-thread; `IsSupported` no-ops safely on unsupported platforms. Pure-managed P/Invoke over `<fenv.h>` (no native build asset); arm64 + x64 across macOS/Linux/Windows; wired into `Foundation` so `Game2D`/`Game3D`/`Server` get it. Controls the FP register only, not JIT codegen variance (FMA/vectorization) - see the new determinism guidance in `USING-KHAOZENGINE.md`. Ships a repro harness + a CI tiering-0/1 determinism step.
- **7.9.0**: `KhaozEngine.Gui` hover glow now blooms as a soft halo with smooth falloff to zero instead of a hard rim hugging the widget edge. The old glow expanded the quad by only half the softness, so the SDF falloff was truncated at ~50% coverage on the quad's flat edge (a tacked-in outline). The glow and the `FillStyled` drop shadow now share a `GuiDraw.SoftRoundedQuad` helper that keeps the SDF box body-sized while expanding the quad past it, so the falloff resolves to zero before the quad edge; a new optional `SpriteBatch.DrawRounded(... inset)` parameter (default 0, byte-identical) makes that possible. `GuiStyle.Modern`'s glow/shadow alphas were retuned for the softer look. Glow-off / flat styles stay byte-identical; new `gui_button_glow` golden, others unmoved.
- **7.8.0**: The remaining retained `KhaozEngine.Gui` widgets (`Slider`, `Toggle`, `Panel`, `Dropdown`, `TextInput`, `PopupPanel`, `ScrollablePanel`) gain a `GuiStyle Style` field (mirroring the retained `Button`) and route their body/handle/thumb fills through `GuiDraw.FillStyled`/`HoverGlow`, so the whole retained set inherits the 7.7.0 modern look (rounded/shadow/gradient/glow) when `Style = GuiStyle.Modern` is set. Each widget keeps its own per-element colour fields (passed as the body/border colours); per widget, only some sub-elements round (slider track stays flat, thumb rounds; toggle becomes a pill; popup scrim/title bar stay flat). Flat default (`GuiStyle.Default`) is byte-identical to before; goldens unmoved. Finishes the 7.7.0 retained-widget follow-up.
- **7.7.0**: Modern UI primitives in `KhaozEngine.Gui` (rounded corners, vertical gradients, soft drop shadow, hover glow) via a new SDF path in the shared Render2D `SpriteBatch` (64B vertex, per-vertex mode flag; plain draws stay byte-identical), plus a procedural tintable icon system (core outline set + game-extensible string registry, no shipped asset) and `IconButton`/`StatChip` composed widgets. All opt-in via `GuiStyle` (new `Modern` preset); the immediate-mode `GuiSurface` widgets and the retained `Button` adopt it, the other retained widgets follow later. Defaults render exactly as before.
- **7.6.0**: Reusable "attention" pulse VFX in `KhaozEngine.Render2D.Vfx`. New `AttentionBeacon.Draw(batch, ring, glow, center, in p, time)` and `VfxRenderer.DrawAttentionBeacon(batch, center, in p, time)` draw an additive point-of-interest pulse: `RingCount` expanding, phase-staggered sonar-ping rings (fading to zero at `MaxRadius`) plus `GlintCount` twinkling glints at deterministic golden-angle offsets (no per-frame RNG/alloc), each on its own `TwinkleRate` phase. Tunables on the new `AttentionBeaconParams` record struct (with `GlintStyle.Disc`/`Star`); `RingCount = 0` and `GlintCount = 0` draw nothing. Stateless/time-driven like `EnergyBeam`; existing goldens unaffected. Replaces Nullwake's bespoke timed-reward aura once it pins this.
- **7.5.0**: Generic translucent filled-fan primitive on the Render3D debug overlay. New `DebugFillShapes.FilledFan(tris, center, rim, closed)` and `Scene3D.DebugFilledFan(center, rim, color, closed = true)` fan an arbitrary, already-ordered boundary polygon out from a centre point (each adjacent rim pair becomes `(center, rim[i], rim[i+1])`, plus a wrap triangle when `closed`), the arbitrary-polygon counterpart to `DebugFilledQuad`/`DebugFilledCircle`. Same CCW winding convention as `FilledCircle`; degenerate input (under 2 rim points) draws nothing. Lets a consumer fill a star-shaped visibility polygon (e.g. a turret's line-of-sight area) that quads and discs can't express.
- **7.4.0**: Point/segment geometry for swept collision. New `Segment2D.DistanceToSegment(p, a, b, out t)` in `KhaozEngine.Collision` returns the shortest distance from a point to the segment `[a, b]` (clamped closest point, not the infinite line) plus the clamped `[0,1]` projection parameter `t` for ordering hits along a swept path; degenerate `a == b` returns `|p - a|`, `t = 0`. Lets a fast mover's look-ahead sweep catch a thin target it would tunnel past if only the endpoints were tested. Deterministic explicit-component math like `CircleCollision`.
- **7.3.0**: Reusable auto-updater last-mile glue. New `IUpdateStatus` decouples UI from `UpdateService`; `KhaozEngine.Gui` gains `UpdateOverlayView` + `UpdateOverlayScreen` (themeable via `UpdateOverlayTheme`, raises events, wired to the new `UpdateOverlayActions.Trigger`); `UpdaterShim.Main` makes a game's updater exe a one-liner; the new `KhaozEngine.Updates.Tool` (`ke-updater`) dotnet tool does manifest/genkey/sign/verify; and a parameterized `publish-update.sh` template + "Adopting the updater" docs ship in the Updates package. Gui now depends on Updates. Security model unchanged.
- **7.2.0**: Round (cylindrical) end-caps for `EnergyBeam` (`KhaozEngine.Render2D.Vfx`): `BeamParams.Caps` (`BeamCap.None`|`Round`, default `None`) draws a soft disc cap of radius half the band's pulse-adjusted width at each end of both the glow band and core, so the beam reads as a capsule instead of a hard rectangle. Caps scale with the pulse, use each band's own colour/alpha (glow under, core over), are independent of `FlareRadius`, and need the glow texture. Default keeps square ends; all existing goldens byte-identical.
- **7.1.0**: Textured, depth-interleaved billboards in `Scene3D`: `DrawBillboard(TextureHandle, pos, size, sourceUv, tint, blend)` draws sprite-sheet frames as depth-sorted quads INTO the lit model pass (depth test, no write) so meshes and sprites occlude each other both ways; alpha+additive, sub-rect UV for frame selection, submission-order blending. The colour-only overlay billboard and all existing goldens stay byte-identical. Adds `GpuBlendAttachment.PreserveDestination` + `GpuDepthStencilState.DepthTestLessEqualNoWrite`. Unblocks SpaceGame's mesh-pivot WS1.5 (enemy billboards in the player/drone mesh scene).
- **7.0.1**: Cap the updater version-check probe: `HttpUpdateSource.CheckLatestVersionAsync` reads the `/latest` response with a bounded buffer (`MaxLatestVersionBytes`, default 64 KiB) before parsing instead of an unbounded `GetFromJsonAsync`, closing a memory-exhaustion DoS from a hostile host. Additive; returns null on over-cap or malformed. Residual risk from the 7.0.0 review.
- **7.0.0**: Updater security hardening (BREAKING): mandatory RSA-signed manifests, https+same-host feed lock, path-traversal/reparse/codesign apply guards, downgrade enforcement, size+disk caps. `TrustedPublicKeys` now required.
- **6.6.0**: Generic 2D VFX module under `KhaozEngine.Render2D.Vfx` (engine-first, driven by Nullwake's mining VFX): pooled zero-alloc screen-space particles (`Particle2DSystem`/`Particle2DEmitterConfig`) with gravity, drag, rotation+angular velocity, sway, size/colour lerp and per-particle blend; an animated additive `EnergyBeam` with endpoint flares; CPU-baked glow/ring textures (`VfxTextures`) and a `VfxRenderer` owner (`DrawGlow`/`DrawRing`/`DrawBeam`). Adds per-quad additive blending to `SpriteBatch` (`BlendMode`); the alpha path is byte-identical. Trauma-based shake reuses the existing `Effects.ScreenShake`. Unblocks Nullwake's rendering wiring.
- **6.5.0**: Dynamic point lights in the lit mesh pass: `Scene3D.AddLight(pos, color, radius, intensity)` (per-frame, cleared each `Begin()`, capped at `Scene3D.MaxPointLights`=16, host picks N-nearest) adds attenuated diffuse + cheap specular on top of key+fill+ambient. Zero lights is byte-identical. Unblocks SpaceGame's 2.5D mesh pivot (WS1); transparent-background compositing was already in place (`TransparentBackground`, 5.70.0).
- **6.4.0**: `Game2D` umbrella now bundles `KhaozEngine.Effects` (`ScreenShake`/game-feel), flowing transitively into `Game3D`. Closes the last omni-package gap (Effects was the only leaf no metapackage pulled in); packaging-only, byte-identical.
- **6.3.0**: Additive helpers unblocking Nullwake's 6.x adoption: `Color` scalar-multiply and `Lerp`, plus `InputManager.GetScrollIn(Rect)` for region-scoped wheel scrolling. Rendering byte-identical.
- **6.2.0**: Cross-platform clip-space correction via `GpuClip.Correct(viewProj, caps)`, adapting world-to-clip to each backend's clip-Y convention (identity on Metal/D3D, flips on Vulkan). No Metal behavior change; the inverted-Y path is correct-by-construction but unvalidated on non-Metal hardware.
- **6.1.0**: Post-6.0 cleanup: dropped a per-frame `WaitForIdle` in `Render3DPreview`, unified the line/fill/billboard overlay renderers, zero-alloc music streaming and `World.ForEach`, fail-loud Gui viewport defaults, and Debug-level logging on swallowed errors.
- **6.0.0**: BREAKING, first 6.x: new zero-dep `KhaozEngine.Primitives` leaf (`Color` with hex, `DeterministicRng`, `XorRng`, `MathUtil`, `ViewportMath`, `Easing`); the public color API everywhere now takes `Primitives.Color` instead of `Vector4`. Adds Ecs save `FormatVersion` gating, migration seam, and `[ComponentId]`; Audio moves to deterministic RNG. Rendering byte-identical.

- **2.2.0**: New `KhaozEngine.Time` package with `GameClock` (real vs scaled sim delta, time-scale, pause/resume); `Screens.ScreenManager` adopts it.
- **2.1.0**: New `KhaozEngine.Content` package: `ConfigLoader.Load<T>` (embedded/disk JSON) and `JsonSchemaValidator` with a bundled validator tool and a build-time data-validation target.
- **2.0.0**: Unified versioning: Input/Screens/UI/Ecs share one version line and `v*` tag scheme (retiring the separate `ecs-v*` line). No functional change from 0.2.1 / 1.6.0.
- **Ecs 1.0.0-1.6.0**: The ECS matured on its own version line: a rewrite to a struct-based archetype ECS (versioned `Entity`, `ref Get<T>`, `ForEach`, command buffer) at 1.0.0, then `WorldSerializer`, change detection, parent-child hierarchy, named system groups, deterministic iteration, and the determinism model (`EntityCommandBuffer.Defer`, typed event channel, `DeterministicRng`).
- **0.1.0-0.2.1**: Initial release and early fixes: four packages extracted from Hardpoint/Nullwake/SpaceGame: `Input` (unified pointer, `IsTapIn` press-origin click-through invariant, drag/scroll/pinch, gamepad/menu nav), `Screens` (routed screen stack), `UI` (`PrimitiveRenderer`, widgets), and a minimal `Ecs`. Plus XML docs, READMEs, and input/click/progress-bar fixes.
