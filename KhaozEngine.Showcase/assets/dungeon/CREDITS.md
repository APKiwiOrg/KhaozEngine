# Dungeon kit credits

The six greybox meshes in this folder (`dungeon_floor.glb`, `dungeon_wall.glb`,
`dungeon_doorframe.glb`, `dungeon_stair.glb`, `dungeon_landing.glb`, `dungeon_ceiling.glb`) are
**self-generated, CC0 (public domain)** placeholder assets for `KhaozEngine.Dungeon`.

- Author: KhaozEngine project (generated, not sourced from a third party)
- License: CC0 1.0 Universal (public domain dedication)
- Generated by `tools/DungeonKitGen` (`Program.cs`), a run-once tool built on SharpGLTF's
  `MeshBuilder`. Each piece is a flat-gray (`Vector4(0.5, 0.5, 0.55, 1)`) box or box assembly, authored
  at its exact final size with the origin at the piece's base center, matching the dimensions in
  `dungeon.manifest.json`. Re-run the tool to regenerate. The output `.glb` files are committed so no
  build step is required to load the kit.

These are greybox placeholders for early integration and tests, not final art. See
`dungeon.manifest.json` and `KhaozEngine.Dungeon`'s `DungeonKitMap.Greybox()` for how the ids map to
the abstract dungeon piece vocabulary.
