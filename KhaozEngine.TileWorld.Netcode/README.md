# KhaozEngine.TileWorld.Netcode

Server-authoritative, client-predicted movement for a `KhaozEngine.TileWorld` tile world. A player IS a tile, a
plane and a facing, and a step commits every N ticks along a deterministic route.

Full API documentation lands with the package's first release. See
`docs/design/TILE-WORLD-NETCODE-DESIGN-2026-08-22.md` for the design.
