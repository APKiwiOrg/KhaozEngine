# KhaozEngine.UI

A game-agnostic MonoGame widget library: Button, Slider, Toggle, Dropdown, ScrollablePanel,
TextInput, Tooltip, MenuTile, and more, plus a `PrimitiveRenderer` and a `TextInputHandler`.
Widgets consume [`KhaozEngine.Input`](https://www.nuget.org/packages/KhaozEngine.Input)'s bounds
helpers, so they are click-through-safe by construction.

`LayoutConstants.TopBarHeight` / `BottomNavHeight` are settable so each game fits its own chrome.

Full docs: [KhaozEngine README](https://github.com/APKiwi/KhaozEngine) and
[the consumer contract](https://github.com/APKiwi/KhaozEngine/blob/main/docs/USING-KHAOZENGINE.md).
