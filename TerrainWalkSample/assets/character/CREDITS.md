# Character asset

`Knight.glb` is from the **KayKit Character Pack : Adventurers (1.0)** by Kay Lousberg
(www.kaylousberg.com), released under **CC0 1.0** (public domain). Source:
https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0

It is a rigged + animated character (41-bone skin, full locomotion clip set: `Idle`,
`Walking_A`, `Running_A`, `Jump_Start`, `Jump_Idle`, etc.), ingested through the engine's
SKINNED path (`GltfLoader.LoadSkinned` + `GltfLoader.LoadAnimations`) so the rig and the
animation channels are preserved (it is NOT flattened like the props). See `LICENSE.txt`.
