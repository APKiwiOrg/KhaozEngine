# KhaozEngine.Render3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `KhaozEngine.Render3D`, an experimental retro/pixel 3D module (orthographic iso camera, glTF lit/cel model draw, low-res pixel post-process chain) on a custom Veldrid+Metal foundation with no MonoGame dependency, plus a standalone sample to judge the look by eye.

**Architecture:** Veldrid (GPU) + Veldrid.SPIRV (GLSL→SPIR-V→MSL at load) + SharpGLTF (model load), all confined to this package and hidden behind engine-native types. `System.Numerics` math. Scene renders the lit model into a low-res render target, runs a toggleable fullscreen post chain, point-upscales to the window. A `Render3DHost` owns the SDL2/Metal window so consumers never see Veldrid.

**Tech Stack:** net10.0, Veldrid 4.9.0, Veldrid.SPIRV 1.0.15, SharpGLTF.Core, GLSL #version 450, xUnit.

**Spec:** `docs/superpowers/specs/2026-06-15-render3d-custom-engine-design.md`

**Execution note:** GPU rendering is eyeball-judged on a Metal window; it cannot run on the headless CI test runner. Only `IsoCamera3D` math gets CI unit tests. Rendering tasks are verified by running the sample and/or the offscreen smoke check described in each task. Prefer **inline execution** (subagents cannot eyeball a Metal window).

## Task 1: IsoCamera3D (TDD — the only CI-tested unit)

**Angle convention (must match tests):** Y up, right-handed. Eye sits at
`Target + Distance * dirToEye` where `dirToEye = (cosE*sinA, sinE, cosE*cosA)` (A=Azimuth, E=Elevation).
`Forward = normalize(Target - Eye) = -dirToEye`. `View = CreateLookAt(Eye, Target, UnitY)`.
`Projection = CreateOrthographic(height*Aspect/Zoom, height/Zoom, Near, Far)` with `height = OrthoSize`.

```csharp
using System;
using System.Numerics;
using KhaozEngine.Render3D;
using Xunit;

namespace KhaozEngine.Tests.Render3D
{
    public class IsoCamera3DTests
    {
        static Vector2 ProjectNdc(IIsoCamera3D cam, Vector3 world)
        {
            Vector4 clip = Vector4.Transform(new Vector4(world, 1f), cam.ViewProjection);
            return new Vector2(clip.X / clip.W, clip.Y / clip.W);
        }

        [Fact]
        public void Defaults_are_iso_angles()
        {
            var cam = new IsoCamera3D();
            Assert.Equal(MathF.PI / 4f, cam.Azimuth, 5);
            Assert.Equal(MathF.Atan(0.5f), cam.Elevation, 5);
        }

        [Fact]
        public void Forward_matches_azimuth_elevation()
        {
            var cam = new IsoCamera3D { Azimuth = MathF.PI / 4f, Elevation = MathF.Atan(0.5f) };
            float cE = MathF.Cos(cam.Elevation), sE = MathF.Sin(cam.Elevation);
            float cA = MathF.Cos(cam.Azimuth), sA = MathF.Sin(cam.Azimuth);
            var expected = -Vector3.Normalize(new Vector3(cE * sA, sE, cE * cA));
            Assert.True(Vector3.Distance(expected, cam.Forward) < 1e-4f, $"{cam.Forward} != {expected}");
        }

        [Fact]
        public void Target_projects_to_center()
        {
            var cam = new IsoCamera3D { Target = new Vector3(3, 1, -2) };
            var ndc = ProjectNdc(cam, cam.Target);
            Assert.True(MathF.Abs(ndc.X) < 1e-4f && MathF.Abs(ndc.Y) < 1e-4f, ndc.ToString());
        }

        [Fact]
        public void Vertical_offset_of_half_orthosize_projects_to_top_edge()
        {
            // Move the target point up along the camera's up axis by half the vertical world extent.
            var cam = new IsoCamera3D { OrthoSize = 10f, AspectRatio = 1f, Zoom = 1f };
            // camera up axis = row pattern from view: use the inverse-ish; derive from View matrix.
            Matrix4x4.Invert(cam.View, out var invView);
            var camUp = Vector3.Normalize(new Vector3(invView.M21, invView.M22, invView.M23));
            var p = cam.Target + camUp * (cam.OrthoSize * 0.5f);
            var ndc = ProjectNdc(cam, p);
            Assert.True(MathF.Abs(ndc.Y - 1f) < 1e-3f, $"ndc.Y={ndc.Y}");
        }

        [Fact]
        public void Zoom_scales_projection()
        {
            var a = new IsoCamera3D { OrthoSize = 10f, AspectRatio = 1f, Zoom = 1f };
            var b = new IsoCamera3D { OrthoSize = 10f, AspectRatio = 1f, Zoom = 2f };
            Matrix4x4.Invert(a.View, out var inv);
            var camUp = Vector3.Normalize(new Vector3(inv.M21, inv.M22, inv.M23));
            var p = a.Target + camUp * 1f;
            float ya = ProjectNdc(a, p).Y, yb = ProjectNdc(b, p).Y;
            Assert.True(MathF.Abs(yb - 2f * ya) < 1e-3f, $"ya={ya} yb={yb}");
        }
    }
}
```

`KhaozEngine.Render3D/Camera/IsoCamera3D.cs`:

```csharp
using System;
using System.Numerics;

namespace KhaozEngine.Render3D
{
    /// <summary>
    /// Orthographic (no perspective) isometric camera. Defaults reproduce a 2:1 iso look
    /// (azimuth 45°, elevation atan(0.5) ≈ 26.57°). Angle, ortho size/zoom, and target are all
    /// configurable so true-iso 30–35° can be tried by eye. Pure System.Numerics, no GPU.
    /// </summary>
    public sealed class IsoCamera3D : IIsoCamera3D
    {
        /// <summary>Rotation about the Y (up) axis, radians. Default 45°.</summary>
        public float Azimuth = MathF.PI / 4f;
        /// <summary>Tilt above the horizontal, radians. Default atan(0.5) ≈ 26.57° (2:1 iso).</summary>
        public float Elevation = MathF.Atan(0.5f);
        /// <summary>World-space point the camera looks at.</summary>
        public Vector3 Target = Vector3.Zero;
        /// <summary>Vertical world extent covered by the viewport (before zoom). Larger = more zoomed out.</summary>
        public float OrthoSize = 10f;
        /// <summary>Zoom multiplier (2 = twice as large on screen).</summary>
        public float Zoom = 1f;
        /// <summary>Viewport aspect (width/height).</summary>
        public float AspectRatio = 16f / 9f;
        /// <summary>Distance of the eye from the target (ortho: affects clipping, not size).</summary>
        public float Distance = 50f;
        public float NearPlane = 0.1f;
        public float FarPlane = 200f;

        Vector3 DirToEye
        {
            get
            {
                float cE = MathF.Cos(Elevation), sE = MathF.Sin(Elevation);
                float cA = MathF.Cos(Azimuth), sA = MathF.Sin(Azimuth);
                return Vector3.Normalize(new Vector3(cE * sA, sE, cE * cA));
            }
        }

        public Vector3 Eye => Target + DirToEye * Distance;
        public Vector3 Forward => -DirToEye;

        public Matrix4x4 View => Matrix4x4.CreateLookAt(Eye, Target, Vector3.UnitY);

        public Matrix4x4 Projection
        {
            get
            {
                float h = OrthoSize / Zoom;
                float w = h * AspectRatio;
                return Matrix4x4.CreateOrthographic(w, h, NearPlane, FarPlane);
            }
        }

        public Matrix4x4 ViewProjection => View * Projection;
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Numerics;
using SharpGLTF.Geometry;
using SharpGLTF.Geometry.VertexTypes;
using SharpGLTF.Materials;
using SharpGLTF.Scenes;

// Subdivided icosahedron -> normalized to a unit sphere, flat per-triangle normals for a faceted retro look.
static (List<Vector3> v, List<int> i) Ico(int subdiv)
{
    float t = (1 + MathF.Sqrt(5)) / 2;
    var verts = new List<Vector3>
    {
        new(-1,t,0), new(1,t,0), new(-1,-t,0), new(1,-t,0),
        new(0,-1,t), new(0,1,t), new(0,-1,-t), new(0,1,-t),
        new(t,0,-1), new(t,0,1), new(-t,0,-1), new(-t,0,1),
    };
    var tris = new List<int>{0,11,5,0,5,1,0,1,7,0,7,10,0,10,11,1,5,9,5,11,4,11,10,2,10,7,6,7,1,8,
        3,9,4,3,4,2,3,2,6,3,6,8,3,8,9,4,9,5,2,4,11,6,2,10,8,6,7,9,8,1};
    for (int s = 0; s < subdiv; s++)
    {
        var nt = new List<int>(); var mid = new Dictionary<long,int>();
        int Mid(int a,int b){ long key=(long)Math.Min(a,b)*100000+Math.Max(a,b);
            if(mid.TryGetValue(key,out var m))return m; var vm=Vector3.Normalize((verts[a]+verts[b])/2);
            verts.Add(vm); mid[key]=verts.Count-1; return verts.Count-1; }
        for(int f=0;f<tris.Count;f+=3){int a=tris[f],b=tris[f+1],c=tris[f+2];int ab=Mid(a,b),bc=Mid(b,c),ca=Mid(c,a);
            nt.AddRange(new[]{a,ab,ca, b,bc,ab, c,ca,bc, ab,bc,ca});}
        tris=nt;
    }
    for(int k=0;k<verts.Count;k++) verts[k]=Vector3.Normalize(verts[k]);
    return (verts, tris);
}

var (vs, idx) = Ico(2);
var mat = new MaterialBuilder("body").WithUnlitShader()
    .WithBaseColor(new Vector4(0.85f, 0.55f, 0.30f, 1f)); // warm base so lighting reads
var mesh = new MeshBuilder<VertexPosition, VertexEmpty, VertexEmpty>("ico");
var prim = mesh.UsePrimitive(mat);
for (int f = 0; f < idx.Count; f += 3)
{
    var p0 = vs[idx[f]]; var p1 = vs[idx[f+1]]; var p2 = vs[idx[f+2]];
    prim.AddTriangle(new VertexPosition(p0), new VertexPosition(p1), new VertexPosition(p2));
}
var scene = new SceneBuilder();
scene.AddRigidMesh(mesh, Matrix4x4.Identity);
var model = scene.ToGltf2();
var outPath = System.IO.Path.GetFullPath("../../KhaozEngine.Render3D/assets/testmodel.glb");
System.IO.Directory.CreateDirectory(System.IO.Path.GetDirectoryName(outPath)!);
model.SaveGLB(outPath);
Console.WriteLine("wrote " + outPath + " verts=" + vs.Count + " tris=" + idx.Count/3);
```

```csharp
using System.Numerics;

namespace KhaozEngine.Render3D
{
    /// <summary>Interleaved vertex: position, flat normal, base color (RGBA).</summary>
    public struct ModelVertex
    {
        public Vector3 Position;
        public Vector3 Normal;
        public Vector4 Color;
        public ModelVertex(Vector3 p, Vector3 n, Vector4 c) { Position = p; Normal = n; Color = c; }
        public const uint SizeInBytes = 40; // 3*4 + 3*4 + 4*4
    }

    /// <summary>CPU-side loaded mesh. GPU buffers are created internally by the renderer.</summary>
    public sealed class GltfMesh
    {
        public ModelVertex[] Vertices { get; }
        public ushort[] Indices { get; }
        public GltfMesh(ModelVertex[] v, ushort[] i) { Vertices = v; Indices = i; }
        public int TriangleCount => Indices.Length / 3;
    }
}
```

- [ ] **Step 2: Loader**

`KhaozEngine.Render3D/Models/GltfLoader.cs`:

```csharp
using System;
using System.Collections.Generic;
using System.Numerics;
using SharpGLTF.Schema2;

namespace KhaozEngine.Render3D
{
    /// <summary>Loads a glTF/GLB at runtime via SharpGLTF into a flat-shaded <see cref="GltfMesh"/>.</summary>
    public static class GltfLoader
    {
        public static GltfMesh Load(string path)
        {
            ModelRoot root = ModelRoot.Load(path);
            var verts = new List<ModelVertex>();
            var indices = new List<ushort>();

            foreach (var mesh in root.LogicalMeshes)
            foreach (var prim in mesh.Primitives)
            {
                var pos = prim.GetVertexAccessor("POSITION")?.AsVector3Array();
                if (pos == null) continue;
                Vector4 baseColor = prim.Material?.FindChannel("BaseColor")?.Parameter is var p && p != null
                    ? new Vector4(p.Value.X, p.Value.Y, p.Value.Z, p.Value.W)
                    : new Vector4(0.8f, 0.8f, 0.8f, 1f);

                var tri = prim.GetTriangleIndices();
                foreach (var (a, b, c) in tri)
                {
                    Vector3 p0 = pos[a], p1 = pos[b], p2 = pos[c];
                    Vector3 n = Vector3.Normalize(Vector3.Cross(p1 - p0, p2 - p0)); // flat per-triangle
                    foreach (var pp in new[] { p0, p1, p2 })
                    {
                        indices.Add((ushort)verts.Count);
                        verts.Add(new ModelVertex(pp, n, baseColor));
                    }
                }
            }
            if (verts.Count == 0) throw new InvalidOperationException("glTF has no triangles: " + path);
            return new GltfMesh(verts.ToArray(), indices.ToArray());
        }
    }
}
```

If `FindChannel("BaseColor")?.Parameter` doesn't compile against SharpGLTF 1.0.5 (API drift), fall back to
`prim.Material?.FindChannel("BaseColor")?.Color ?? new Vector4(0.8f,0.8f,0.8f,1f)` — check the installed
SharpGLTF surface with `dotnet build` and adjust the accessor; the rest is stable.

- [ ] **Step 2: GLSL sources (the heart of the look)**

`KhaozEngine.Render3D/Internal/ShaderSources.cs` — see the full source block below. All are GLSL `#version 450`, compiled via Veldrid.SPIRV. The model pass writes 3 MRT color targets (lit color, encoded normal, linear depth) so the edge pass needs no depth-texture sampling.

```csharp
namespace KhaozEngine.Render3D.Internal
{
    internal static class ShaderSources
    {
        // ---- Model pass ----
        public const string ModelVert = @"#version 450
layout(set=0, binding=0) uniform Cam { mat4 ViewProj; mat4 Model; };
layout(location=0) in vec3 Position;
layout(location=1) in vec3 Normal;
layout(location=2) in vec4 Color;
layout(location=0) out vec3 vNormalVS;
layout(location=1) out vec4 vColor;
layout(location=2) out float vDepth;
void main() {
    vec4 world = Model * vec4(Position, 1.0);
    gl_Position = ViewProj * world;
    // normal in world space (model is rotation+uniform-scale for the POC)
    vNormalVS = normalize(mat3(Model) * Normal);
    vColor = Color;
    vDepth = gl_Position.z / gl_Position.w; // 0..1 (Veldrid clip space)
}";

        public const string ModelFrag = @"#version 450
layout(set=0, binding=1) uniform Light {
    vec4 LightDir;    // xyz
    vec4 LightColor;
    vec4 Ambient;
    vec4 Params;      // x = CelBands
};
layout(location=0) in vec3 vNormalVS;
layout(location=1) in vec4 vColor;
layout(location=2) in float vDepth;
layout(location=0) out vec4 oColor;
layout(location=1) out vec4 oNormal;
layout(location=2) out vec4 oDepth;
void main() {
    vec3 N = normalize(vNormalVS);
    float ndl = max(dot(N, -normalize(LightDir.xyz)), 0.0);
    float bands = Params.x;
    if (bands >= 1.0) ndl = floor(ndl * bands + 0.5) / bands; // cel
    vec3 lit = vColor.rgb * (Ambient.rgb + LightColor.rgb * ndl);
    oColor = vec4(lit, 1.0);
    oNormal = vec4(N * 0.5 + 0.5, 1.0);
    oDepth = vec4(vDepth, vDepth, vDepth, 1.0);
}";

        // ---- Shared fullscreen triangle ----
        public const string FullscreenVert = @"#version 450
layout(location=0) out vec2 vUv;
void main() {
    vec2 p = vec2((gl_VertexIndex << 1) & 2, gl_VertexIndex & 2);
    vUv = p;
    gl_Position = vec4(p * 2.0 - 1.0, 0.0, 1.0);
}";

        // ---- Palette quantize (+ optional Bayer dither) ----
        public const string PaletteFrag = @"#version 450
layout(set=0, binding=0) uniform sampler2D Src;
layout(set=0, binding=1) uniform Pal { vec4 Colors[64]; vec4 Info; }; // Info.x=count, .y=ditherOn
layout(location=0) in vec2 vUv;
layout(location=0) out vec4 oColor;
const float bayer[16] = float[16](
    0.0,8.0,2.0,10.0, 12.0,4.0,14.0,6.0, 3.0,11.0,1.0,9.0, 15.0,7.0,13.0,5.0);
void main() {
    vec3 c = texture(Src, vUv).rgb;
    if (Info.y > 0.5) {
        ivec2 px = ivec2(gl_FragCoord.xy);
        float th = (bayer[(px.y & 3) * 4 + (px.x & 3)] / 16.0 - 0.5);
        c += th * (1.0 / 8.0); // spread before snap
    }
    int count = int(Info.x);
    float best = 1e9; vec3 bestC = c;
    for (int i = 0; i < count; i++) {
        vec3 pc = Colors[i].rgb; float d = dot(c - pc, c - pc);
        if (d < best) { best = d; bestC = pc; }
    }
    oColor = vec4(bestC, 1.0);
}";

        // ---- Depth/normal edge outline ----
        public const string EdgeFrag = @"#version 450
layout(set=0, binding=0) uniform sampler2D Color;
layout(set=0, binding=1) uniform sampler2D NormalTex;
layout(set=0, binding=2) uniform sampler2D DepthTex;
layout(set=0, binding=3) uniform Edge { vec4 OutlineColor; vec4 Texel; vec4 Thresh; }; // Texel.xy=1/size, Thresh.x=depth, .y=normal
layout(location=0) in vec2 vUv;
layout(location=0) out vec4 oColor;
void main() {
    vec3 base = texture(Color, vUv).rgb;
    float d0 = texture(DepthTex, vUv).r;
    vec3 n0 = texture(NormalTex, vUv).rgb * 2.0 - 1.0;
    float edge = 0.0;
    vec2 offs[4] = vec2[4](vec2(Texel.x,0), vec2(-Texel.x,0), vec2(0,Texel.y), vec2(0,-Texel.y));
    for (int i = 0; i < 4; i++) {
        float d = texture(DepthTex, vUv + offs[i]).r;
        vec3 n = texture(NormalTex, vUv + offs[i]).rgb * 2.0 - 1.0;
        if (abs(d - d0) > Thresh.x) edge = 1.0;
        if ((1.0 - dot(n, n0)) > Thresh.y) edge = 1.0;
    }
    oColor = vec4(mix(base, OutlineColor.rgb, edge), 1.0);
}";

        // ---- Point upscale blit ----
        public const string BlitFrag = @"#version 450
layout(set=0, binding=0) uniform sampler2D Src;
layout(location=0) in vec2 vUv;
layout(location=0) out vec4 oColor;
void main() { oColor = texture(Src, vUv); }";
    }
}
```

- [ ] **Step 2: ModelRenderer — pipeline + per-frame draw into the MRT**

`KhaozEngine.Render3D/Rendering/ModelRenderer.cs`: builds the model pipeline (`CreateFromSpirv(ModelVert, ModelFrag)`, vertex layout Position/Normal/Color = Float3/Float3/Float4, `Outputs = ModelFB.OutputDescription`, depth test LessEqual, cull None for the POC). Two uniform buffers: `Cam { mat4 ViewProj; mat4 Model; }` and `Light { vec4 LightDir; LightColor; Ambient; Params; }` in one ResourceSet (set 0, bindings 0/1). `Draw(cl, mesh, viewProj, model, settings)` updates uniforms, clears MRT (color→ambient, normal→0, depth→1), draws indexed.

- [ ] **Step 3: PixelPostProcess — palette/edge/blit pipelines + chain**

`KhaozEngine.Render3D/Rendering/PixelPostProcess.cs`: builds three fullscreen pipelines (palette, edge, blit) over `FullscreenVert`. Uniform/resource layouts per the shaders. `Run(cl, RenderResources res, Framebuffer swapchainFB, PixelPostProcessSettings s)`:
1. start = `res.ColorTex`.
2. if `s.Quantize`: set palette UBO (colors[], count, ditherOn = s.Dither?1:0), draw fullscreen `start → PingA`. start = PingA.
3. if `s.Outline`: set edge UBO (outline color, texel=1/size, thresholds), bind (start, NormalTex, DepthTex), draw `→ PingB`. start = PingB.
4. blit `start → swapchainFB` with the **point** sampler (crisp pixelation upscale). Always runs.
Ping-pong so step 3 never reads its own output. (If `Quantize` is off, start stays `ColorTex`; edge reads it fine.)

- [ ] **Step 4: Scene3D — public consumer API**

`KhaozEngine.Render3D/Scene3D.cs`:

```csharp
using System.Numerics;
using Veldrid;
using KhaozEngine.Render3D.Internal;

namespace KhaozEngine.Render3D
{
    /// <summary>
    /// A drawable retro-3D scene: an <see cref="IsoCamera3D"/>, one model, and a pixel post chain.
    /// Owns the internal Veldrid resources; consumers never see Veldrid. Created by <see cref="Render3DHost"/>.
    /// </summary>
    public sealed class Scene3D : System.IDisposable
    {
        readonly GraphicsDevice _gd;
        readonly CommandList _cl;
        ModelRenderer _model = null!;
        PixelPostProcess _post = null!;
        RenderResources _res = null!;
        GltfMesh? _mesh;
        DeviceBuffer? _vb, _ib;
        float _spin;

        public IsoCamera3D Camera { get; } = new();
        public PixelPostProcessSettings Post { get; } = new();

        internal Scene3D(GraphicsDevice gd) { _gd = gd; _cl = gd.ResourceFactory.CreateCommandList();
            Rebuild(Post.LowResWidth, Post.LowResHeight); }

        public void LoadModel(GltfMesh mesh) { /* create _vb/_ib from mesh */ _mesh = mesh; }
        public void Spin(float dt) { _spin += dt * 0.6f; }

        void Rebuild(int w, int h) { /* (re)create _res, _model, _post for size */ }

        /// <summary>Render lit model → low-res RT → post chain → the host's swapchain framebuffer.</summary>
        public void Render(Framebuffer swapchainFB, float aspect)
        {
            if (_res.Width != Post.LowResWidth || _res.Height != Post.LowResHeight)
                Rebuild(Post.LowResWidth, Post.LowResHeight);
            Camera.AspectRatio = (float)Post.LowResWidth / Post.LowResHeight;
            _cl.Begin();
            if (_mesh != null) {
                var modelM = Matrix4x4.CreateRotationY(_spin) * Matrix4x4.CreateRotationX(0.15f);
                _model.Draw(_cl, _vb!, _ib!, _mesh.Indices.Length, Camera.ViewProjection, modelM, Post);
            }
            _post.Run(_cl, _res, swapchainFB, Post);
            _cl.End();
            _gd.SubmitCommands(_cl);
        }
        public void Dispose() { /* dispose owned resources */ }
    }
}
```

`Render` takes a Veldrid `Framebuffer` but that overload is `internal`-reachable only via `Render3DHost`;
the public surface consumers actually call (Task 6) is `Render3DHost.Run` + `Scene3D.Camera/Post/Spin/LoadModel`.
Mark the `Framebuffer` overload `internal` and add no public Veldrid-typed members. (Move `Render(Framebuffer,...)`
to `internal void RenderInternal(...)`; keep public members Veldrid-free.)
